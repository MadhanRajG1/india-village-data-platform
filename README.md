# 🇮🇳 India Village Data Platform

## 📌 Project Overview
This project builds a structured backend system for India's village-level geographical data.

---

## ⚙️ Tech Stack
- Python (Pandas, Flask)
- MySQL
- Excel

---

## 🔄 Workflow
1. Data cleaned using Excel
2. Combined using Python
3. Stored in MySQL database
4. API built using Flask

---

## 🌐 API Endpoints

- /states → Get all states
- /districts?state=XYZ → Get districts
- /subdistricts?district=XYZ → Get subdistricts
- /villages?subdistrict=XYZ → Get villages

---

## 📊 Features
- Cleaned large dataset
- Hierarchical data structure
- REST API for data access
- Basic data visualization
